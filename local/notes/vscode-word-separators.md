# VSCode 中文标点分词

## 问题

双击选词无法在中文全角标点处断开。例如 `验证1：问`，双击 `验证1` 会选中整串 `验证1：问`；冒号换成半角 `:` 则能正常只选中 `验证1`。

## 原因

VSCode 双击选词（以及 `Ctrl+方向键` 按词跳转）把「不在 `editor.wordSeparators` 列表里的字符」都当作单词字符。默认列表只含 ASCII 标点，全角中文标点（`：` 等）不在其中，于是被当作单词的一部分。

## 解决

在 `settings.json`（macOS: `~/Library/Application Support/Code/User/settings.json`）中把中文标点追加进默认列表：

```json
{
  "editor.wordSeparators": "`~!@#$%^&*()-=+[{]}\\|;:'\",<.>/?，。！？；：、·…—～￥（）【】｛｝《》〈〉“”‘’「」『』"
}
```

前半段是 VSCode 默认的 ASCII 标点（必须保留），后半段是常用全角标点。改完即时生效，无需重启。

## 注意

- 该设置全局生效，不支持 per-language 覆盖。若某些场景希望选中含书名号/引号的整段（如 Markdown 标题 `《xxx》`），无法按语言单独关闭。
- 若想要相反方向的需求（双击中文按词而非整段选中），需分词类扩展，与此设置无关。
